# Dataset Instructions

The recommendation system expects the dataset at:

`data/tmdb_5000_movies.csv`

To run the project:

1. Obtain the TMDB 5000 Movie Dataset from a source that permits your intended use.
2. Place the CSV file in this folder.
3. Make sure the filename is exactly `tmdb_5000_movies.csv`.
4. Run the application from the project root directory.

The dataset is not included in this repository.
